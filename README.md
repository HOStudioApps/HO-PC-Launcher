# HO PC Launcher

A customizable desktop launcher widget for Windows.

## Features

- Favorite Apps Panel
- Memo Panel
- Audio Controls
- Display Brightness Controls
- Customizable Layout
- Multiple Profiles
- Theme Customization
- Multi-language Support
